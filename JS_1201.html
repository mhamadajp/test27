武器① 相加相乗平均と「重み付き和」＆「整数の壁」

・正の数 a, b で (√a − √b)² ≧ 0 より a ＋ b ≧ 2√(ab)（等号は a ＝ b）。

・重み付き和 x ＋ ky ＝ C のワザ：「x」と「ky」の2つに相加相乗平均を使うと、C ＝ x ＋ ky ≧ 2√(kxy) ⇒ xy ≦ C²/(4k)（等号は x ＝ ky ＝ C/2）。

・⚠️ 超重要：実数上限がちょうど整数になっても、等号の (x, y) が整数でないとその上限は実現しない（例：問10の x＋4y＝20 では上限25は実現せず最大値24！）。必ず等号に近い整数で実現を確認する！

武器② 平方数の余り（4で割った余り・8で割った余り）

・整数 n を 4 で割った余りが 0, 1, 2, 3 のとき、n² を 4 で割った余りは 0（偶数）か 1（奇数）だけ！

・よって 2つの平方数の和 x² ＋ y² を 4 で割った余りは 0, 1, 2 のみ（絶対に 3 にならない！）。

・さらに余りが 2 なら「1 ＋ 1」しかあり得ないのでx, y はともに奇数、余りが 1 なら偶奇が異なると一瞬で見抜ける！

・発展（mod 8）：n² を 8 で割った余りは 0, 1, 4 のみ（3変数の和 x²＋y²＋z² ＝ 8m＋7 の不可能証明で大活躍！）。

武器③ 連続する平方数の間隔で挟む（非平方の証明）

・16（＝4²）と 25（＝5²）の間に整数の平方数はない。一般に非負整数 k に対し、k² ＜ M ＜ (k ＋ 1)² を満たす整数 M は絶対に平方数にならない！

・見つけ方のコツ：式を平方完成（または展開比較）して、n² の係数が 1 なら (n＋a)² と (n＋a＋1)² の間に挟めるか「差が正（＞0）であること」を確かめる！
