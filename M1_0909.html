ステップ 1

式から「中心」を見つける：二乗の中身をゼロにする点

式： $y = (x - 2)^2 + 1$

「$(x-2)$ だから頂点の $x$ 座標は $2$」と符号を機械的に暗記すると、プラスとマイナスで迷子になりがちです。
本質は「二乗の中身 $(x-2)$ がちょうど $0$ になる瞬間を探すこと（$x-2=0$ を解く）」にあります。

👆 グラフ上をなぞって $x$ を動かせます 原点 $(0,0)$ 基準
現在の点： (2.0, 1.0)
x = 2.0
式のパーツの計算 値
中身 $(x - 2)$： 0.00
二乗 $(x - 2)^2$： 0.00（二乗は常に 0 以上！）
高さ $y = (x-2)^2 + 1$： 1.00
🎯 $x = 2$ のとき： $(x-2) = 0$ となり、二乗部分が最も小さい $0$ になります。だから頂点は $(2, 1)$ で軸は $x=2$ です！
ステップ 2

なぜ放物線は左右対称になるの？（二乗の魔法）

軸 $x = 2$ を挟んだペアを観察

軸 $x = 2$ から「左へ $d$」「右へ $d$」進んだ2つの点を見てみましょう。
符号は逆でも、二乗すると $(-d)^2 = (+d)^2 = d^2$ となって同じ値になるため、高さ $y$ が完全に一致します！

● 左側の点 $(2-d, y)$ | 軸 $x=2$ | ● 右側の点 $(2+d, y)$
0 (頂点) 1 (Q2: 1と3) 2 (Q2: 0と4) $\frac{5}{2}$
向き x の値 差 $(x - 2)$ 二乗 $(x - 2)^2$ 高さ $y$
左へ $d$
右へ $d$
💡 左右対称の理由：
差は $-d$ と $+d$ で正負が逆ですが、二乗すると $(-d)^2 = (+d)^2 = d^2$ に化けるため、高さ $y$ が完全に同じになります。これが放物線の美しい対称性の正体です！
ステップ 3

$a$ が変わると何が変わる？（縦の上昇スピード）

頂点 $(2, 1)$ は共通で $a$ を比較

グラフの細さ・太さは感覚ではなく、「頂点から横に 1 離れたとき、縦に何マス上がるか」で決まります。
3つの式を同時に見比べてみましょう。

● A: $a=1$ ● B: $a=2$ (急上昇) ● C: $a=\frac{1}{2}$ (緩やか)
横の距離でステップ比較：
頂点からの横の距離 A ($a=1$) の縦の変化 B ($a=2$) の縦の変化 C ($a=\frac{1}{2}$) の縦の変化
0 0 0 0
1 $+1$ ($1 \times 1^2$) $+2$ ($2 \times 1^2$) $+\frac{1}{2}$ ($\frac{1}{2} \times 1^2$)
2 $+4$ ($1 \times 2^2$) $+8$ ($2 \times 2^2$) $+2$ ($\frac{1}{2} \times 2^2$)
🎯 なぜ $a$ が大きいと細く見えるの？

横に 1 マス進むだけで、B は A の 2倍（$+2$）、C は 半分（$+\frac{1}{2}$）しか上がりません。
$a$ は二乗の変化率を何倍に増幅するかという「ターボ倍率」です。急激に立ち上がるため、縦に引っ張られてスリムに見えます。

ステップ 4

$a$ が負になると？（山型と最大値の理由）

式： $y = -2(x - 2)^2 + 1$

「マイナスがついたら上凸」と丸暗記していませんか？
実数の二乗 $(x-2)^2$ は絶対に $0$ 以上（$\ge 0$）です。そこに負の数（$-2$）を掛けると必ず $0$ 以下（$\le 0$）に反転します！

頂点： (2, 1) が一番高い「てっぺん（最大値）」
符号の切り替え比較：
🔍 なぜ下向き（上に凸）で最大値になるのか？
1 $(x - 2)^2 \ge 0$ （二乗はマイナスにならない）
2 $-2(x - 2)^2 \le 0$ （$-2$ を掛けると全部ゼロ以下に沈む！）
3 $y = -2(x - 2)^2 + 1 \le 1$

二乗部分が $0$ になるときだけ天辺の $1$ に届き、それ以外の $x$ では必ず $1$ から引き算されて下がります。だから「最大値 1」になります！

原点から頂点へのナビゲーション

基本形 $y=x^2$ の頂点 $(0,0)$ から出発して、式が変わるごとにグラフがどう動くかワープさせてみましょう。

頂点: (0, 0)
式の変化をタップして確認：
👉 設計図の読み方：
$y = a(x - \mathbf{p})^2 + \mathbf{q}$ のとき、$\mathbf{p}$ は横の平行移動（軸）、$\mathbf{q}$ は縦の平行移動（高さ）を直接表しています。
ステップ 6

今度は逆向き：グラフから式を作る！

頂点 $(3, 2)$ と 点 $(4, 4)$

頂点 $(3, 2)$ が分かれば、式の大部分 $y = a(x - 3)^2 + 2$ がもう決まります。
あとは開き具合 $a$ を調整して、ターゲットの点 $(4, 4)$ にピタッと重ねてみましょう！

● 頂点 (3, 2) 通過点 🎯 (4, 4)
まだ点 $(4, 4)$ を通っていません。スライダーで $a$ を調整してみよう！
📘 計算で求める3つの手順：
① 頂点 $(3, 2)$ から型を作る： $y = a(x - 3)^2 + 2$
② 点 $(4, 4)$ を代入する： $4 = a(4 - 3)^2 + 2$
③ $a$ を解く： $4 = a(1) + 2 \implies \mathbf{a = 2}$
