幾何学的な対称性

● 左右の直角三角形に注目！
底辺（中点Mからの距離）: AM = BM = 2
共通の高さ: PM = |y|
中点での交角: 90° (垂直直交)
三平方の定理より：
$$AP = \sqrt{AM^2 + PM^2} = \sqrt{4 + y^2}$$ $$BP = \sqrt{BM^2 + PM^2} = \sqrt{4 + y^2}$$

中点 $M$ を通り、線分 $AB$ に垂直な直線上の点は、どの高さにあっても左右の直角三角形が合同になるため、斜辺の長さは絶対に等しくなります！

★ ここで誕生した言葉 ★

「軌跡（きせき / Locus）」とは？

与えられた条件（今回は「AとBから等距離」）を満たす「点をすべて集めてできる図形」のこと。
1点や2点だけでなく、条件に合うすべての居場所の道筋（コレクション）を表す言葉です！

📐 探究 3 図の見た目だけでなく、数式で完全に証明する

座標 $P(x, y)$ から立式！なぜ計算すると $y$ が消えるのか？

平面上の好きな場所にある点を $P(x, y)$ とおきます。
三平方の定理を使って「2点間の距離の2乗」を等式で結び、式を変形してみましょう。

📝 等距離の翻訳プロセス 言葉「同じ距離」 ➔ 式「AP² = BP²」 ➔ 図形の方程式
A(-2, 0), B(2, 0), P(x, y)
【第1段階】三平方の定理で「距離の2乗」を等しいとおく ※ 距離は正なので AP = BP ⇔ AP² = BP²
$$(x - (-2))^2 + (y - 0)^2 = (x - 2)^2 + (y - 0)^2$$ $$(x + 2)^2 + y^2 = (x - 2)^2 + y^2$$
【第2段階】カッコを展開して整理する
$$(x^2 + 4x + 4) + y^2 = (x^2 - 4x + 4) + y^2$$
両辺から共通の $x^2$, $y^2$, $4$ を引くと…？
$$8x = 0 \quad \Longleftrightarrow \quad x = 0$$

🤔 ここが核心：なぜ式から「y」が消えたのか？

式から $y$ が消えたのは、「高さが0（地面）」という意味ではありません！
これは、「横の座標さえ $x = 0$ であれば、高さ $y$ はどんな値でも（自由・無制限に）等式が成り立つ」という意味です！
だからこそ、答えは1つの点ではなく、縦軸（$y$軸全体）という「直線 $x = 0$」になるのです。

🔄 逆も確かめる（必要十分の確認）

逆に、直線 $x = 0$ 上にある任意の点 $P(0, y)$ を選んだとき：
$AP^2 = (0+2)^2 + y^2 = 4 + y^2$、および $BP^2 = (0-2)^2 + y^2 = 4 + y^2$ となり、
常に $AP^2 = BP^2 \implies AP = BP$ が成り立ちます。
「条件を満たす点は直線 $x=0$ 上にあり、直線 $x=0$ 上の点はすべて条件を満たす」ことが完璧に証明されました！

条件を満たしています！ピンを留めて、上下の空間にもある点を探してみましょう。

💡 横軸（x軸）上にある2つの特殊点：
① 内分点 (AとBの間): P(-2/3, 0)
② 外分点 (Aの外側): P(-6, 0)

もし直線なら交点は1つのはず。2つあるということは…？

数式で平方完成すると：
$$4 AP^2 = BP^2$$ $$4((x+2)^2 + y^2) = (x-2)^2 + y^2$$ $$3x^2 + 3y^2 + 20x + 12 = 0$$ $$\left(x + \frac{10}{3}\right)^2 + y^2 = \frac{64}{9} = \left(\frac{8}{3}\right)^2$$

2乗の項（$3x^2, 3y^2$）が消えずに残ったため、円の方程式になりました！これを古代ギリシャの数学者の名にちなんで「アポロニウスの円」と呼びます。

Takeaway

距離の幾何条件 ⟶ 座標の2乗の等式 ⟶ 図形の方程式（直線・円）
