なぜ境界角が2つ出ても、不等式は終わらないの？

方程式（\(=\)）は「ぴったりその高さになる点」を探すので、境界の角（例: \(\frac{\pi}{6}, \frac{5\pi}{6}\)）だけで完了します。
しかし不等式は「その高さより上（または下）にある場所全体」を求めるため、境界で区切られた円周のどちら側の弧を採用するのかを選ばなければ答えになりません。

💡 合言葉：方程式は「点」、不等式は「点と点をつなぐ弧（角度の帯）」！
「不等号が大きいから角度も大きい方？」という誤解

「\(\sin\theta \ge \frac{1}{2}\) だから \(\theta\) が大きい方を選べばいい」と考えてしまうのは危険です！
大きいのは「角そのもの」ではなく「\(\sin\theta\) の値（単位円での高さ）」です。
例えば \(\theta = 180^\circ (\pi)\) は \(\theta = 90^\circ (\frac{\pi}{2})\) より角は大きいですが、高さは \(\sin\pi = 0\) で低くなってしまいます。

⚠️ 注意：右回しに進んだ角度と、その位置の「高さ・横」は比例しません！
なぜ \(\cos\theta \ge \frac{1}{2}\) の答えは2つに分かれるの？

多くの人が「\(\frac{\pi}{3} \le \theta \le \frac{5\pi}{3}\)」と書いて間違えます。しかしその真ん中にある \(\theta = \pi\) を試すと \(\cos\pi = -1 < \frac{1}{2}\) で条件を満たしません！
単位円の右側にある弧は \(\theta = 0\) のスタート地点をまたいでいるため、角の約束（\(0 \le \theta < 2\pi\)）に従うと「\(0\) から \(\frac{\pi}{3}\)」と「\(\frac{5\pi}{3}\) から \(2\pi\)」の2本の区間に分かれて書く必要があります。

🔍 解：\(0 \le \theta \le \frac{\pi}{3}\) または \(\frac{5\pi}{3} \le \theta < 2\pi\)
なぜ \(\tan\) では \(\frac{\pi}{2}, \frac{3\pi}{2}\) を絶対に含めないのか？

\(\tan\theta = \frac{y}{x}\)（直線の傾き）です。真上（\(\frac{\pi}{2}\)）と真下（\(\frac{3\pi}{2}\)）では、横座標が \(x = 0\) になってしまいます。
数学では「0で割ること」が禁止されているため、これらの角では \(\tan\) の値そのものが定義されません。
不等号に等号（\(\ge\) や \(\le\)）がついていても、\(\frac{\pi}{2}\) と \(\frac{3\pi}{2}\) には絶対に等号をつけてはいけません！

🛡️ 鉄則：\(\tan\) の不等式では垂直線（\(y\) 軸）の角に常に白丸（\(<\)）！
