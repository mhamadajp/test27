何を見るべきか？（視覚ガイド）

$\sin\theta = \frac{1}{2}$
👀 この問題で見るべきポイント

単位円の高さ（縦座標）が $\frac{1}{2}$ になる水色の水平線を引きました。 円周とぶつかった2つの交点（赤い二重丸）の角度が「方程式の解」です！

単位円: 角度 θ と 縦座標 y = sin θ
0 ≦ θ < 2π
グラフ: 横軸＝角度 θ ➜ 縦軸＝値
⚡ 解の角度に直接ジャンプして確認：
θ = \frac{\pi}{6} (30°)

cosθ (横): +0.866

0 すべての原点：「基本形」を単位円で解く

目標: 5分

【発問】この方程式なら解けますか？

$\sin\theta = \frac{1}{2} \quad (0 \leqq \theta < 2\pi)$

「角を暗記しているけれど、いつもど忘れする…」という人は、左の図を見てください。
sinθ は単位円の「縦の高さ」です。高さが $\frac{1}{2}$ になる水色の線を横に引くと、円周と2回ぶつかります（赤い二重丸）。このときの角度が答えです！

左の単位円で赤い二重丸がついている2つの角 θ は、それぞれ何度（何ラジアン）でしょう？

正解！ $\theta = \frac{\pi}{6}, \frac{5\pi}{6}$ です！

左の画面にある「⚡ 解の角度に直接ジャンプ」のボタンを押してみてください。動径がピタッと交点に合わさり、下のグラフでも波が高さ $\frac{1}{2}$ を通っているのが分かりますね。

今日の合言葉：「問題が難しくなるのではなく、この基本形に戻すための手順が増えるだけ」です！

A 係数と定数の整理（一次方程式）

目標: 7分

【例題】 $2\sin\theta - 1 = 0 \quad (0 \leqq \theta < 2\pi)$

何が邪魔で基本形に見えないでしょうか？「-1」と「sin の前の 2」ですね。中学生の一次方程式 2x - 1 = 0 と全く同じ手順で式を整理します！

① まず定数項を移項する： $2\sin\theta = 1$
② 両辺を 2 で割る（基本形！）： $\sin\theta = \frac{1}{2}$
③ 単位円で交点の角を決める： $\theta = \frac{\pi}{6}, \frac{5\pi}{6}$

✍️ その場で1問トライ！ 次の方程式を解いてみよう：

$3\cos\theta + 3 = 0 \quad (0 \leqq \theta < 2\pi)$
整理すると cosθ = ➜ 解 $\theta =$
⭕ 完璧です！ $3\cos\theta = -3$ より $\cos\theta = -1$ 。
左の単位円を見てください！ cos なので今度は横座標（$x$ 座標）を見ます。
赤色の縦線 x = -1 と円が接する角は $\theta = \pi$ の1つだけです！
※「答えは角 θ 」。cosθ = -1 で止めないこと！

B 三角比の二次式と「文字の置き換え」

目標: 10分

【例題】 $2\sin^2\theta - \sin\theta - 1 = 0 \quad (0 \leqq \theta < 2\pi)$

「sin の2乗が出てきて難しそう…」と思うかもしれませんが、sinθ をひとまとまりの文字 t と置けば、高校1年で学んだ普通の二次方程式に変身します！

① 置き換えと変域の確認（超重要！）： $t = \sin\theta \quad (-1 \leqq t \leqq 1)$

② 式を t で書き換えて因数分解する：

$2t^2 - t - 1 = 0 \implies (2t + 1)(t - 1) = 0$

③ t の値を求める：

$t = -\frac{1}{2} \quad \text{または} \quad t = 1$

⚠️ ここで終わってはダメ！ t は自分が勝手に置いた仮の文字。必ず角 θ に戻します！

④ 2本の基本形に分けて単位円で角を求める：

$\sin\theta = -\frac{1}{2}$ (下側の線) 交点は第3・第4象限 $\theta = \frac{7\pi}{6}, \frac{11\pi}{6}$
$\sin\theta = 1$ (最頂点の線) 単位円のてっぺん $\theta = \frac{\pi}{2}$

まとめの解： $\theta = \frac{\pi}{2}, \quad \frac{7\pi}{6}, \quad \frac{11\pi}{6}$

🚨 絶対にやってはいけないNG答案！

方程式 $\cos^2\theta - \cos\theta = 0$ の問題で、「両辺を cosθ で割って cosθ - 1 = 0 にする」のは大間違いです！ cosθ = 0 の解（θ = π/2, 3π/2）が消滅してしまいます。必ず共通因数でくくる cosθ(cosθ - 1) = 0 を行いましょう！

C 一次の三角不等式：答えは角の「区間（範囲）」！

目標: 8分

【方程式との決定的な違い】

方程式の解は「点（特定の角）」でしたが、不等式の解は「連続する区間（角の範囲）」になります。

【例題】 $2\sin\theta - 1 \geqq 0 \quad (0 \leqq \theta < 2\pi)$
手順1（整理） ➜ $\sin\theta \geqq \frac{1}{2}$
手順2（境界角） ➜ $\sin\theta = \frac{1}{2}$ となる境界角は $\theta = \frac{\pi}{6}, \frac{5\pi}{6}$
手順3（単位円） ➜ 左の図を見てください！高さ $\frac{1}{2}$ 以上の青く光るエリアの弧をなぞります。
条件を満たす角の範囲： $\frac{\pi}{6} \leqq \theta \leqq \frac{5\pi}{6}$
※「≧」なので両端の境界角も含みます

✍️ 即時練習： $2\cos\theta + 1 < 0 \quad (0 \leqq \theta < 2\pi)$ を解くとどうなる？

整理すると $\cos\theta < -\frac{1}{2}$ です。cos は横座標なので、$x < -\frac{1}{2}$ （縦の境界線より左側）の範囲を探します。

⭕ 大正解！ 元の不等号が「<（未満）」なので、境界角は含まれず等号なし（<）になります。

D 積の不等式：入試頻出の思考プロセス

目標: 7分

【入試型例題】 $\sin\theta(2\sin\theta - 1) \leqq 0 \quad (0 \leqq \theta < 2\pi)$

「2つのものを掛け算して ≦ 0（0以下）」になるのはどんなときでしょうか？ 「t = sinθ と置いたときの2次不等式」として見てみましょう！

① まず文字 t の不等式として解く：

$t(2t - 1) \leqq 0 \implies 0 \leqq t \leqq \frac{1}{2}$

つまり、sinθ の高さが「0以上、かつ $\frac{1}{2}$ 以下」の帯に入る角 θ を探します！

② 境界となる4つの角を単位円でマーク：

  • $\sin\theta = 0 \implies \theta = 0, \pi$
  • $\sin\theta = \frac{1}{2} \implies \theta = \frac{\pi}{6}, \frac{5\pi}{6}$

③ 単位円で $0 \leqq y \leqq \frac{1}{2}$ の帯の中にある弧をなぞる：

円周を反時計回りに $0$ から進むと、条件を満たす区間が2つに分かれて現れます（左の図の青い2本の弧）：

$0 \leqq \theta \leqq \frac{\pi}{6} \quad \text{または} \quad \frac{5\pi}{6} \leqq \theta \leqq \pi$

⚠️ 注意：θ = 2π は範囲 0 ≦ θ < 2π に含まれないため、2π を答えに書いてはいけません！
