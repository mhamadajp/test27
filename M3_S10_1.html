2. 微分を逆向きに読む

3つの位置の式があります。それぞれを時間 t で微分すると、どんな「速さ」になるでしょうか？

位置を表す式 微分すると速さ 出発位置 (t=0)
s₁(t) ＝ t² 2t 0 m
s₂(t) ＝ t² ＋ 3 2t ＋3 m
s₃(t) ＝ t² − 4 2t −4 m
三つの位置の式に共通すること：

グラフの形（カーブの曲がり具合）・微分した速さ（すべて 2t）

違うこと：

グラフの上下のズレ（切片）・t＝0 での出発位置

💡 重要：定数項（＋3 や −4）は微分すると 0 になるため、「速さ 2t」からは出発位置が消えてしまっています！
生徒用ワークシート 1ページ目 2連動
3つの位置グラフ s(t) と、各点での接線の傾き（速さ） 傾き s'(t) ＝ 2t （すべて一致！）
現在時刻 t ＝ 2.0 秒
接線の傾き（瞬間の速さ） ＝ 4.0 m/s

👆 グラフ上を左右に動かすと、どの高さのグラフでも「同じ時刻なら接線の傾き（速さ）が完全に平行」なことが確かめられます！

3

3. 自分の言葉でまとめる

速さが 2t だと分かっても、出発位置を表す数 C は決まりません。 元の位置をまとめて s(t) ＝ t² ＋ C と書きます。

微分すると 2t になる元の式全体をこう書く！
∫ 2t dt ＝ t² ＋ C
（C は任意の定数：積分定数）

・∫（インテグラル）：「微分すると 2t になる式を全部探す」という合図

・dt：「時間 t について逆に戻すよ」という目印

・＋ C を付ける理由：定数は微分すると 0 になるため、速さだけからでは「どこからスタートしたか」が1つに決まらないから！

出発位置 C を動かしてみよう： C ＝ ＋2.0 m
生徒用ワークシート 1ページ目 3連動
不定積分 ∫ 2t dt ＝ t² ＋ C が表す「無限の曲線群」 どの曲線も微分すると 2t

スライダーで C を変えると、グラフが上下にスライドします。どの曲線を選んでも曲がり具合（傾き）は全く変わりません！

4

4. べきの形を逆にたどる

微分すると「指数が1つ下がり、元の指数が前に掛かる」ルールでした。
逆にたどるにはどうすればよいでしょう？

まず微分する 戻したい増え方 元の式を予想
(x³)' ＝ 3x² x² (1/3) x³ ＋ C
(x⁴)' ＝ 4x³ x³ (1/4) x⁴ ＋ C
(x⁸)' ＝ 8x⁷ x⁷ (1/8) x⁸ ＋ C
🔑 べき関数の不定積分の合言葉：

「指数を1つ上げて、その新しい指数で割る！」

∫ xⁿ dx ＝ ( 1 / (n ＋ 1) ) xⁿ⁺¹ ＋ C
生徒用ワークシート 1ページ目 4連動
「予想した式」を微分して検算するリアルタイムチェッカー
目標の増え方:
検算: ( (1/3)x³ ＋ C )' ＝ (1/3) × 3x² ＝ x² ✓ 完全一致！
5

基本問題 答えと検算を一緒に（生徒用ワークシート 2ページ目）

① ∫ x² dx ＝
(1/3) x³ ＋ C 検算: ((1/3)x³)' = x² ✓
② ∫ x dx ＝
(1/2) x² ＋ C 検算: ((1/2)x²)' = x ✓
③ ∫ 6x⁵ dx ＝
x⁶ ＋ C 検算: (x⁶)' = 6x⁵ ✓
6

少し先を見てみる（数学IIIの発展と例外）

(x⁻²)' ＝ −2x⁻³ を利用して ∫ x⁻³ dx を求める (x ≠ 0)：
∫ x⁻³ dx ＝ − (1/2) x⁻² ＋ C ＝ − 1 / (2x²) ＋ C

負の指数でも「指数を1つ上げて(−2)、それで割る」公式がそのまま使えます！

⚠️ 大発見！ x⁻¹ ＝ 1/x に同じ公式を使うとどうなる？

指数を1つ上げると x⁰ ＝ 1。しかし定数1を微分すると 0 になってしまい、元の 1/x に戻りません！（分母も 0 で割ることになり計算不能）

👉 「x⁻¹ ＝ 1/x だけはこの公式が【使えない】特別な例外！」

（※次の授業で登場する「自然対数 log |x|」へとつながる大切な伏線です）

べき関数の不定積分 完全ナビゲーター

自然数だけでなく、負の整数や分数、そして「なぜ 1/x だけ公式が使えないのか」まで視覚的に一覧探索できます。

x³ の積分 (n ＝ 3)

∫ x³ dx ＝ (1/4) x⁴ ＋ C

微分すると: ((1/4)x⁴)' ＝ x³

x² の積分 (n ＝ 2)

∫ x² dx ＝ (1/3) x³ ＋ C

微分すると: ((1/3)x³)' ＝ x²

x の積分 (n ＝ 1)

∫ x dx ＝ (1/2) x² ＋ C

微分すると: ((1/2)x²)' ＝ x

定数 1 の積分 (n ＝ 0)

∫ 1 dx ＝ x ＋ C

微分すると: (x)' ＝ 1

x⁻³ の積分 (n ＝ −3)

∫ x⁻³ dx ＝ −(1/2) x⁻² ＋ C

微分すると: (−(1/2)x⁻²)' ＝ x⁻³

x⁻² ＝ 1/x² の積分 (n ＝ −2)

∫ x⁻² dx ＝ −x⁻¹ ＋ C ＝ −1/x ＋ C

微分すると: (−1/x)' ＝ 1/x²

⚠️ x⁻¹ ＝ 1/x の例外 (n ＝ −1) 公式適用不可！

∫ (1/x) dx ＝ log |x| ＋ C （公式 (1/(n+1))xⁿ⁺¹ だと 1/0 で破綻！）

指数を1つ上げると x⁰=1 となり微分が0になってしまう唯一の特異点です。

被積分関数 f(x) ＝ xⁿ（白）と その原始関数 F(x)（青）の比較グラフ 選択中: n ＝ 2 (f(x)=x², F(x)=(1/3)x³)

🧭 不定積分を解き明かす「思考の3ステップ」

STEP 1: 微分の逆を予想する

「何を微分したらこの増え方になるか？」を考え、べきなら指数を1つ上げて係数を調整します。

STEP 2: 積分定数 ＋ C を添える

増え方（速さ）だけでは出発位置が決まらないため、無数にある平行な可能性を代表して ＋ C を付けます。

STEP 3: 微分して必ず検算する

求めた式を微分し、インテグラルの内側の式に戻ることを1行で確かめればミスは絶対にゼロになります！
