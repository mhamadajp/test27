4. 分数式も見える形にする

一見難しそうに見える分数式 ∫ ( (x² ＋ 2x) / x ) dx。
分子全体を一度に考えず、分母の x で割って項ごとにバラバラに分けるのが最大の秘訣です！

① 分母の x で分子をそれぞれ割る (x ≠ 0)：
(x² ＋ 2x) / x ＝ (x² / x) ＋ (2x / x) ＝ x ＋ 2
② あとはいつものように1項ずつ積分する：
∫ (x ＋ 2) dx ＝ (1/2) x² ＋ 2x ＋ C
💡 迷ったら逆向きに掛けてみよう！

x(x ＋ 2) ＝ x² ＋ 2x と展開して元に戻るか確かめれば、割り算のミスは絶対に防げます！

生徒用ワークシート 1ページ目 4連動
分数式の分離ビジュアライザー（x ≠ 0） (x² ＋ 2x) / x ＝ x ＋ 2
⚠️ x ＝ 0 では分母が0になるため白丸（定義されない）

割ることで複雑な分数式が、見慣れた「直線 x ＋ 2」に姿を変える様子が分かります！

5. 1/x だけは立ち止まる（生徒用ワークシート 2ページ目）

⚠️ x⁻¹ ＝ 1/x をいつもの方法で戻そうとすると？

指数を1増やすと x⁰ ＝ 1。しかし定数1を微分しても 0 になってしまい、1/x に戻りません！（分母も 1/(−1＋1) ＝ 1/0 で計算不能！）

既習の対数微分を逆向きに読む！
∫ (1 / x) dx ＝ log |x| ＋ C （x ≠ 0）

・なぜ絶対値 |x| が付く？：x が負のときでも、対数の中身（真数）を正にするため！

・x ＝ 0 は？：1/x も log|x| も定義されないため、範囲から除外する。

分数式の分離 ＆ log|x| の特異点完全ナビ

分子を分母で割るテクニックと、なぜ 1/x の積分だけに対数 log|x| が現れ、絶対値が必要なのかを視覚的に解明します。

1. 分数式をバラバラに割るテクニック（タップして展開）
例題: (x² ＋ 2x) / x

＝ x ＋ 2

積分: (1/2)x² ＋ 2x ＋ C (x ≠ 0)

発展: (2x² ＋ 3x ＋ 1) / x

＝ 2x ＋ 3 ＋ 1/x

積分: x² ＋ 3x ＋ log|x| ＋ C (x ≠ 0)

高次: (x³ − 4x) / x

＝ x² − 4

積分: (1/3)x³ − 4x ＋ C (x ≠ 0)

💡 なぜ log|x| に絶対値が付くのか？（負の側の微分検証）

・x > 0 のとき: ( log x )' ＝ 1/x
・x < 0 のとき: 真数を正にするため log(−x) を合成微分すると、( log(−x) )' ＝ ( 1 / (−x) ) × (−1) ＝ 1/x！
👉 正でも負でも、まとめて log |x| と書けば、x ≠ 0 のすべての範囲で微分すると 1/x に完全一致します！

被積分関数 f(x) ＝ 1/x（白破線）と その原始関数 F(x) ＝ log|x|（ピンク実線） 左右両側で接線の傾きが 1/x

🧭 足し算の不定積分を解く「分解の3ステップ」

STEP 1: 項ごとにバラバラに色分けする

足し算や引き算は、焦らず項ごとに分離。分数式なら分母で割って単項式の和にします。

STEP 2: 1/x だけは絶対に立ち止まる！

普通のべき関数は「指数を1上げて割る」、定数は「xを添える」。しかし 1/x だけは対数「log|x|」を使います。

STEP 3: ＋ C を添えて微分で検算する
