「増え方が足し算なら、元の長さも項ごとに足し合わせるだけ！」

リボンの伸びる速さが \(r(t) = 2t + 3 \ \mathrm{cm/s}\) のとき、全体の長さ \(L(t)\) は「3つの成分の合計」でできています。

復元の公式
$$\int (2t+3) \, dt = t^2 + 3t + C$$
【3つの成分の関係性】全体の長さ \(L(t)\) はどう成り立っている？
① 初期の長さ \(C\) スタート時の長さ
\(C = 5\,\mathrm{cm}\) など

最初からあった長さ。時間によって変化しないため、微分すると \(0\) になって増え方に現れない。

② 定速の伸び \(3t\) 一定ペースで増えた分
\(3 \times t\) 秒

毎秒 \(3\,\mathrm{cm}\) ずつ等速で伸びる。\(t\) 秒後には \(3t\,\mathrm{cm}\) 伸びる（微分すると \(3\) に戻る）。

③ 加速の伸び \(t^2\) 加速しながら増えた分
\(t^2\,\mathrm{cm}\)

毎秒 \(2t\,\mathrm{cm/s}\) とだんだん速くなりながら伸びる。\(t\) 秒後には \(t^2\,\mathrm{cm}\) 伸びる（微分すると \(2t\) に戻る）。

全体の長さ: \(C\) + \(3t\) + \(t^2\) （微分すると \(\to\) \(0\) + \(3\) + \(2t\) ）

最大の疑問：「3」と「C」は何が違うの？

① 定数の「3」は『伸びる速さ』

毎秒 \(3\,\mathrm{cm}\) のペースで伸び続けるため、\(t\) 秒後には \(3t\,\mathrm{cm}\) 増えます。
微分検算: \((3t)' = 3\) （1次式を微分すると傾き3が残る）

② 積分定数「C」は『スタートの長さ』

最初からリボンが持っていた長さ。時間経過によって変化しないため、伸びる速さ（微分）には現れず消えてしまいます。
微分検算: \((C)' = 0\) （定数を微分すると0で消滅）

増え方（微分）と元の式（積分）の対応
増え方 \(r(t)\) 元の式 \(L(t)\) 微分で検算
\(2t\) \(t^2\) \((t^2)' = 2t\)
\(3\) \(3t\) \((3t)' = 3\)
\(0\)（現れない） \(C\) \((C)' = 0\)
\(2t + 3\) \(t^2 + 3t + C\) \((t^2+3t+C)' = 2t+3\)
和・差・定数倍の公式

「バラバラにして元に戻し、最後に +C を添える」

微分の性質 \(\{ k f(x) + l g(x) \}' = k f'(x) + l g'(x)\) の逆向きのルールです。

$$\int \{ k f(x) + l g(x) \} \, dx = k \int f(x) \, dx + l \int g(x) \, dx$$

ステップ式 分解工房

手動シミュレーション
よくある間違い：係数の調整忘れ！

\(\int (2x^2 + 3) \, dx\) を解くとき、うっかり \(x^3 + 3x + C\) と答えてしまう人が非常に多いです！

微分して確かめてみよう：
\((x^3 + 3x + C)' = 3x^2 + 3\)

\(x^2\) の係数が \(3\) になってしまい、元の \(2x^2\) より大きくなってしまいます！

正しい係数の作り方：

\(x^2\) を積分すると \(\frac{x^3}{3}\)。これに係数 \(2\) が掛かるので、
\(2 \cdot \frac{x^3}{3} = \mathbf{\frac{2}{3}x^3}\) となります。

なぜ +C は 1つだけでよいの？

「第1項の積分で \(+C_1\)、第2項の積分で \(+C_2\) と別々に付けなくていいの？」と思うかもしれません。

\(( \dots + C_1 ) + ( \dots + C_2 ) = \dots + (C_1 + C_2)\)

定数と定数を足しても「また別の1つの定数」になるため、最初からまとめて末尾に \(+C\) を1つだけ 添えれば十分です。

分数式の攻略法

「分数は、項ごとに分けてから積分する！」

分数の形のまま積分できる魔法の公式はありません。まず割り算を実行して整式に直します。

$$\frac{x^2+2x}{x} = \frac{x^2}{x} + \frac{2x}{x} = x + 2 \quad (x \neq 0)$$

分数式の「ハート形分割」ビジュアライザー

分子を分母で割る
分子の項をそれぞれ分母で割る変形

なぜ「\(x \neq 0\)」と書く必要があるの？

定義域の穴

式を約分して \(x+2\) に変形したとしても、元の式には分母に \(x\) がありました。 数学では「\(0\) で割ること」が禁止されているため、\(x=0\) は最初から存在してはいけない値（穴）になります！

グラフ上では、直線 \(y = x+2\) の \(x=0\) の地点 \((0, 2)\) に 白抜きの穴（未定義点） が空いています。そのため、答えには必ず「\((x \neq 0)\)」という注意書きを添えます。
やってはいけない大間違い！

「分子を積分して \(\frac{x^3}{3} + x^2\)、分母を積分して \(\frac{x^2}{2}\) として割り算する」
という計算は 完全に誤り です！（微分の割り算も単純に分母分子を微分できなかったのと同じです）

べき公式が使えない唯一の例外

「なぜ \(1/x\) の積分だけは \(\log|x|\) になるのか？」

「指数を1増やす」と \(0\) になってしまう壁を、対数関数の微分で乗り越えます。

$$\int \frac{1}{x} \, dx = \log |x| + C \quad (x \neq 0)$$

導関数 \(y = \frac{1}{x}\) と 原始関数 \(y = \log|x| + C\) の連動

下のスライダーで \(x\) を動かすと、接線の傾きが常に \(\frac{1}{x}\) に一致することが分かります。

現在: \(x = \) 2.0
増え方（導関数）: \(y = \frac{1}{x}\) y = 0.50
元の式（原始関数）: \(y = \log|x|\) y = 0.69
調べたい \(x\) の値（マイナスも試してみよう）：
-3.0 +3.0

なぜ絶対値 \(|x|\) がつくの？

対数の真数は「正の数」でなければなりません（\(\log(-2)\) などは存在しない）。 しかし導関数 \(\frac{1}{x}\) は \(x < 0\) の世界でも存在します！

\(x < 0\) のとき： \(-x > 0\) なので \(\log(-x)\) を微分すると、
\(\{\log(-x)\}' = \frac{1}{-x} \cdot (-1) = \mathbf{\frac{1}{x}}\)

マイナス同士が打ち消し合って、なんと \(x < 0\) でも微分結果は \(\frac{1}{x}\) に戻ります！ 正の世界（\(\log x\)）と負の世界（\(\log(-x)\)）を1本の式でまとめるために \(\log |x|\) と書きます。

\(x=0\) を除く2つの決定的な理由
  • \(\frac{1}{x}\) 自体に \(x=0\) を代入できない（分母が0）。
  • 対数関数 \(\log |0|\) も定義されない（\(-\infty\) に発散）。
💡 ちょっと深い話（定数の独立性）

\(x>0\) と \(x<0\) は \(x=0\) で完全に分断されているため、厳密には正の側の定数 \(C_1\) と負の側の定数 \(C_2\) を別々に選ぶことができます。
