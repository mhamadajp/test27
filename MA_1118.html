なぜ「3辺から同じ距離」なの？

  • 「真ん中」の正体：円が敷地からはみ出さないためには、中心から境界線（辺）までの最短距離＝垂線の長さが半径以上である必要があります。
  • 円が辺に接するとき：接点までの半径はその辺と垂直になります。同じ円の半径はすべて等しいので、3辺すべてに接する円の中心は「3辺への垂線の長さがすべて等しい点」になります。
  • 注意（よくある誤解）：「3つの頂点から等しい距離」ではありません！（上の「頂点までの距離と比較」にチェックを入れて確認しよう。頂点から等距離なのは外心です）
現実とのつながりメモ：三角形の敷地なら内接円が最大の円になりますが、実際の公園や施設では出入口・地形・安全規則なども考えるため、数学の「内心」は条件をシンプルにしたモデルとして役立ちます。
ミッション② 性質の発見と根拠の証明

「3辺から等距離の点」は、どうやって見つければいい？

いきなり3辺すべてから等しい距離の点を探すのは大変です。そこで数学では「まず2辺から等距離の点」を集めてみます！下のステップボタンを押しながら、図形の性質を発見しましょう。

操作：頂点 A, B, C をドラッグしてどんな三角形でも成り立つか試そう
ステップ ① スライダーで点Pを動かしてみよう

角Aの2辺から等距離の点は「角の二等分線」上に並ぶ！

二等分線上の点 P の位置 PH = PK を確認

$\angle A$ の二等分線上の点 $P$ から、2辺 $AB, AC$ に垂線 $PH, PK$ を下ろします。

【合同の証明】$\triangle APH$ と $\triangle APK$ において

・垂線なので $\angle AHP = \angle AKP = 90^\circ$

・斜辺 $AP$ が共通

・角の二等分線なので $\angle HAP = \angle KAP$

→ 直角三角形の斜辺と1つの鋭角がそれぞれ等しいので $\triangle APH \equiv \triangle APK$。よって $PH = PK$！

※逆（角の内部で2辺への垂直距離が等しい点）も成り立つため、「2辺から等距離の点の集合 ＝ 角の二等分線」です。

ステップ ②

$\angle A$ と $\angle B$ の二等分線の交点 $I$ をとる

$\angle A$ の二等分線だけでは、辺 $BC$ までの距離も同じとは限りません。そこで、$\angle B$ の二等分線も引いて交点 $I$ を作ります。

1. $I$ は $\angle A$ の二等分線上にあるので、
（辺ABまでの距離）＝（辺ACまでの距離）

2. $I$ は $\angle B$ の二等分線上にあるので、
（辺ABまでの距離）＝（辺BCまでの距離）

→ つまり、交点 $I$ は3辺 $AB, BC, CA$ すべてから等しい距離にある！

ステップ ③ 結論！

$\angle C$ の二等分線も同じ点 $I$ を通り、「内心」が確定！

ステップ②で、交点 $I$ はすでに「辺 $CA$ と辺 $CB$ からも等距離」であることが分かりました。

したがって $I$ は必ず $\angle C$ の二等分線上にも乗ります。つまり三角形の3つの内角の二等分線は必ず1点 $I$ で交わります！

★ 重要用語と3つの基本性質

・この交点 $I$ を三角形の内心（Incenter）という。

・$I$ を中心に3辺に接する円を内接円、その半径 $r$ を内接円の半径という。

・鈍角三角形でも直角三角形でも、内心 $I$ は必ず三角形の内部にある。

ミッション③ 公式を暗記せず、図を分解して納得しよう

公式の成り立ち（ここが納得ポイント！）

3つの小三角形は、高さがすべて内接円の半径 $r$ で共通です（モードBで横に並べると高さが一直線に揃います！）。

$S = \triangle IBC + \triangle ICA + \triangle IAB$
$S = \frac{1}{2}ar + \frac{1}{2}br + \frac{1}{2}cr$
$S = \frac{1}{2}r(a + b + c)$
半周長 $s = \frac{a+b+c}{2}$ とおくと、 $S = rs$
⚠️ よくあるテストのミス：
「$r =$ 面積 $\div$ 周長」としてしまい、2倍大きい値で割ってしまうミスが多発します！三角形の面積には $\frac{1}{2}$ がつくので、割るのは周長ではなく半周長 $s$ です。

🎓 本日の到達目標まとめ（内心の3本柱）

① 角度の性質

$AI, BI, CI$ はそれぞれの内角の二等分線。特に $\angle BIC = 90^\circ + \frac{1}{2}\angle A$ が成り立つ。

② 距離（内接円）の性質

内心 $I$ から3辺への垂直距離はすべて等しく、内接円の半径 $r$ に一致する。

③ 面積との関係

3つの小三角形に分割することで、$S = \frac{1}{2}r(a+b+c) = rs$（$s$ は半周長）が成り立つ。
