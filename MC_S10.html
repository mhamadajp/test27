「点」と「直線」から同じ距離にある点を全部集めると？

1つの点から等距離の点を集めると「円」になります。では、「決まった点（焦点）」と「決まった直線（準線）」から同じ距離にある点をすべて集めると、どんな曲線が描けるでしょうか？

放物線の基本方程式
$$x^2 = 4py \quad \text{または} \quad y^2 = 4px$$
① 焦点 \(F\) と 準線 \(\ell\)

基準となる固定された「1つの点」と「1本の直線」。直線への距離は必ず垂直に測ります。

② 頂点はちょうど中間

焦点と準線のちょうど真ん中の地点が、放物線の最もカーブが急な「頂点」になります。

③ \(p\) の符号で向きが決まる

焦点がある方向へ向かって開きます（\(p>0\) なら上または右、\(p<0\) なら下または左）。

POE探究サイクル

放物線ビジュアライザー：\(PF = PH\)（等距離の点たち）

曲線上の動点 \(P\) をスライダーで動かして、焦点 \(F\) までの距離と準線までの垂直距離が常に完全に一致することを確かめましょう。

\(x^2 = 12y\)
曲線上の動点 \(P\) を移動させる (整数値): \(P = \left(3, \frac{3}{4}\right)\)
-6 +6
【焦点 \(F\) までの距離 \(PF\)】 \(PF = \frac{15}{4}\)

$$\sqrt{(x - 0)^2 + (y - p)^2}$$

オレンジの点線：焦点 \(F\) と点 \(P\) を結ぶ線分の長さです。

【準線 \(\ell\) までの垂線距離 \(PH\)】 \(PH = \frac{15}{4}\)

$$|y - (-p)| = |y + p|$$

緑色の点線：点 \(P\) から準線へ下ろした垂線の長さ。\(PF = PH\) で常に完全一致！

放物線の設定・プリセット パラメータ p

パラメータ \(p\) を自由に変更: \(p = 3\)
-5 (下/左) 0 (原点) +5 (上/右)
納得のポイント：\(4p\) の「4」ってどこから来る？

\(PF^2 = PH^2\) を三平方の定理で展開すると：
\(x^2 + (y-p)^2 = (y+p)^2\)
両辺を展開して整理すると、\(y^2\) と \(p^2\) が相殺されて
\(x^2 = 2py - (-2py) = 4py\) と、自然に \(4\) が現れます！

楕円（Ellipse）の定義

「2つの焦点からの距離の和がいつも一定」

ピン2本に長さ \(2a\) の糸を掛け、ピンと張ったまま鉛筆を1周させると美しい楕円が描けます。

標準形: $$\frac{x^2}{a^2} + \frac{y^2}{b^2} = 1$$
距離の和 = \(2a\) | 焦点 \(c = \sqrt{a^2 - b^2}\)

「なぜ焦点の計算は引く（\(c^2 = a^2 - b^2\)）のか？」

幾何学の美

楕円ビジュアライザー：\(PF_1 + PF_2 = 2a\)（糸張りシミュレーション）

点 \(P\) を楕円上で1周動かしてみてください。2本の糸の長さは変わっても、合計は常に一定です！

点 \(P\) の位置（回転角度 \(\theta\)）: \(P = (6, 0)\)
0° 360°

\(10\)

\(2\)
合計: \(PF_1 + PF_2\)
\(12 \quad (= 2a)\)

調べる楕円（ワークシート対応）

直角三角形 \(a, b, c\) の秘密

点 \(P\) が短軸のてっぺん \((0, b)\) に来た瞬間を考えると、二等辺三角形ができて \(PF_1 = PF_2 = a\) になります。

底辺 \(c\), 高さ \(b\), 斜辺 \(a\) の直角三角形
$$\mathbf{b^2 + c^2 = a^2 \iff c^2 = a^2 - b^2}$$

※ 斜辺が \(a\)（一番長い長半径）なので、焦点 \(c\) を求める式は「引き算」になります！

双曲線（Hyperbola）の定義

「2つの焦点からの距離の差（の絶対値）が一定」

和を差に変えるだけで、閉じた楕円が外側へ大きく開く2つの枝（双曲線）へとドラマチックに変貌します。

標準形: $$\frac{x^2}{a^2} - \frac{y^2}{b^2} = 1$$
距離の差 = \(2a\) | 焦点 \(c = \sqrt{a^2 + b^2}\)

双曲線ビジュアライザー：\(|PF_1 - PF_2| = 2a\) と漸近線

点 \(P\) を枝に沿って遠くへ動かすと、曲線が点線の「漸近線」に吸い付くように近づいていく様子が観察できます。

距離 ①: \(PF_1\)
\(9\)
距離 ②: \(PF_2\)
\(1\)
距離の差: \(|PF_1 - PF_2|\)
\(8 \quad (= 2a)\)

調べる双曲線（ワークシート対応）

楕円と双曲線の決定的な違い：\(c^2\) の足し引き
楕円（内側に焦点）： 端点 \(a\) より焦点 \(c\) の方が中心に近いので \(c < a\)。
\(\implies \mathbf{c^2 = a^2 - b^2}\)（引き算）
双曲線（外側に焦点）： 頂点 \(a\) より焦点 \(c\) の方が外側にあるので \(c > a\)。
\(\implies \mathbf{c^2 = a^2 + b^2}\)（足し算）
3つの曲線の統一理論

「最初に見るのは、何が一定？」

すべては「距離の決まり」で一貫しています。円の拡大・縮小から楕円への変形も体験してみましょう。

放物線: 等しい (PF = PH)
楕円: 和が一定 (PF₁ + PF₂ = 2a)
双曲線: 差が一定 (|PF₁ - PF₂| = 2a)

円 \(x^2 + y^2 = 36\) を縦方向に縮める実験

円から楕円が生まれる瞬間

半径 \(6\) の正円（灰色の点線）の \(y\) 座標（縦の高さ）だけを上と下からギュッと半分（\(\times \frac{1}{2}\)）に押しつぶす と、紫色の「楕円」が誕生します！

横方向（x軸）の変化
半径 \(a = 6\)（そのまま！）
\(\to x^2 / 6^2 = \mathbf{x^2 / 36}\)
縦方向（y軸）の変化
半径 \(b = 3\)（半分に圧縮！）
\(\to y^2 / 3^2 = \mathbf{y^2 / 9}\)
縦方向の圧縮・拡大倍率 \(k\): \(k = \frac{1}{2} \quad (\text{半分に圧縮})\)
$$\frac{x^2}{36} + \frac{y^2}{9} = 1$$

3曲線の完全見極めマスターシート

要点総整理
【放物線】 \(x^2 = 4py\) または \(y^2 = 4px\) 等距離

基準: 1つの焦点 \(F\) と 1本の準線 \(\ell\)

距離の条件: \(PF = PH\)（焦点までの距離 ＝ 準線までの垂線距離）

【楕円】 \(\frac{x^2}{a^2} + \frac{y^2}{b^2} = 1\) 和が一定

基準: 2つの焦点 \(F_1, F_2\)（長軸の内側）

距離の条件: \(PF_1 + PF_2 = 2a\)（距離の和が長軸長 \(2a\) で一定）

焦点の計算: \(c^2 = a^2 - b^2\)（引き算！）

【双曲線】 \(\frac{x^2}{a^2} - \frac{y^2}{b^2} = 1\) 差が一定

基準: 2つの焦点 \(F_1, F_2\)（頂点の外側）

距離の条件: \(|PF_1 - PF_2| = 2a\)（距離の差が頂点間距離 \(2a\) で一定）

焦点の計算: \(c^2 = a^2 + b^2\)（足し算！）| 漸近線: \(y = \pm \frac{b}{a}x\)

今日の振り返り：3つの重要ポイント

① 放物線は「点と直線から等距離」

\(PF = PH\)。頂点は焦点と準線の中点（原点）。式は \(x^2=4py\) または \(y^2=4px\)。

② 楕円は「2焦点からの距離の和が一定」

\(PF_1 + PF_2 = 2a\)。焦点は長軸の内側にあり、三平方の定理から \(c^2 = a^2 - b^2\)（引き算）。

③ 双曲線は「2焦点からの距離の差が一定」

\(|PF_1 - PF_2| = 2a\)。焦点は頂点の外側にあり、\(c^2 = a^2 + b^2\)（足し算）。漸近線は \(y = \pm \frac{b}{a}x\)。
