ACTIVITY 1 • 座標と比の根本原理

公式より先に「移動」を見る

内分の公式 $\frac{nx_1 + mx_2}{m+n}$ を覚える前に、「全体で何歩進んで、そのうち何歩進むか」という移動（ベクトル）の眼を持ちましょう。

問題 点 $A(-2, 1)$, $B(4, 7)$ を 1 : 2 に内分する点 $P$ の座標
点 $A(-2,1)$ 点 $B(4,7)$ 内分点 $P$ ドラッグで比を直感操作
比 $m : n$ : 1 : 2

思考のステップ

STEP 1: AからBへの「全体の移動量」を見る

終点から始点を引き算します：

$B - A = (4 - (-2), \; 7 - 1) = (6, \; 6)$

$x$ 方向に $+6$、$y$ 方向に $+6$ の「移動」が発生しています。

STEP 2: 比率で「何分のいくつ進むか」決める

比が 1 : 2 のとき、全体は 3 分割。$P$ は $A$ から 1 つ分進んだ場所です。

移動量 = $\frac{1}{3} \times (6, 6) = (2, 2)$
STEP 3: 始点Aに足し算してPへ到達する

始点 $A(-2, 1)$ に移動量を加えるだけで完成：

$P = (-2, 1) + (2, 2) = (0, 3)$
入試での見抜き方・普遍の武器

公式 $\frac{nx_1 + mx_2}{m+n}$ を暗記しようとすると「$m$ と $n$ のクロス」で符号ミスを起こしがちです。しかし、 $\vec{OP} = \vec{OA} + \frac{m}{m+n}\vec{AB}$ という「始点＋移動」の感覚を持っていれば、数Bのベクトルや数Cの空間座標でも全く同一の思考で一撃で復元できます。

ACTIVITY 2 • 代数の発想転換

未知数を解かずに「欲しい形」を作る

方程式を見たら反射的に $x$ を解こうとしていませんか？ 入試では「$x$ は解けないが、式の値は一瞬で求まる」ように仕組まれます。

問題 $x^2 - 6x + 5 = 0$ のとき、$x^2 + \frac{25}{x^2}$ の値を求めよ。
NGアプローチ

力技で $x$ を直接解く

計算地獄・ミス頻発

因数分解 $(x-1)(x-5)=0 \implies x = 1, 5$。
$x=1$ を代入: $1^2 + \frac{25}{1^2} = 1 + 25 = 26$。
$x=5$ を代入: $5^2 + \frac{25}{5^2} = 25 + 1 = 26$。

もし因数分解できない入試問題なら？

例えば $x^2 - 6x + 2 = 0$ だった場合、$x = 3 \pm \sqrt{7}$ となります。
これを $(3+\sqrt{7})^2 + \frac{4}{(3+\sqrt{7})^2}$ に代入して有理化する……？ 試験時間が溶けて計算ミスします。

本質アプローチ

塊（ブロック）の関係性を作る

暗算レベルで求まる
① 逆算: 求めたい式は何の2乗に近いか？

$x^2 + \frac{25}{x^2}$ は、$x$ と $\frac{5}{x}$ を足したものを2乗した形に近い！

$\left(x + \frac{5}{x}\right)^2 = x^2 + 2 \cdot x \cdot \frac{5}{x} + \frac{25}{x^2} = x^2 + \mathbf{10} + \frac{25}{x^2}$
★ 中央の $2ab$ で $x$ と $1/x$ が打ち消し合い、ただの「10」になる！
② 与式から $x + \frac{5}{x}$ を召喚する

$x^2 - 6x + 5 = 0$ において、$x=0$ は不適（$0-0+5 \neq 0$）。
したがって両辺を堂々と $x$ で割ることができます。

$\frac{x^2 - 6x + 5}{x} = 0 \implies x - 6 + \frac{5}{x} = 0 \implies \mathbf{x + \frac{5}{x} = 6}$
③ 2乗して真ん中の定数を引く
$\left(x + \frac{5}{x}\right)^2 = 6^2 = 36$
$x^2 + \frac{25}{x^2} = 36 - 10 = \mathbf{26}$

係数を変えて「構造」を体感する

一次の係数 $p$ ($x^2 - px + q = 0$):
6
定数項 $q$ (中央項 $2q$ に影響):
5
求めたい値 $x^2 + \frac{q^2}{x^2}$ 26 ($6^2 - 2 \times 5 = 26$)
ACTIVITY 3 • 2次関数の最大・最小

場合分けは「頂点の位置」で決まる

場合分けの境界は公式の暗記ではありません。「頂点が区間の端（ゲート）をいつ通過するか」を動かして体感しましょう。

問題 $f(x) = (x-a)^2 - 2a$ の $0 \le x \le 2$ における最小値 $m(a)$
放物線 $y=f(x)$ 定義域 $[0, 2]$ 最小点 $(x_{min}, m(a))$
頂点: $(a, -2a)$
状態: 頂点は区間内
パラメータ $a$ の値をスライドして放物線を旅させる: a = 1.00
-1.5 +3.5
即時チェック:
現在の場合分け領域

【場合②】 $0 \le a \le 2$ のとき

頂点 $x=a$ が区間 $[0, 2]$ の中にすっぽり入っています。下に凸の放物線なので、一番低いのは当然「頂点そのもの」です。

$m(a) = f(a) = -2a$
3つの場合分け一覧
$a < 0$ $x=0$ で最小 $m(a)=a^2-2a$
$0 \le a \le 2$ $x=a$ で最小 $m(a)=-2a$
$2 < a$ $x=2$ で最小 $m(a)=a^2-6a+4$
なぜ境目は $a=0$ と $a=2$ なのか？

区間の「左端の門（$x=0$）」と「右端の門（$x=2$）」を頂点がすれ違うからです。境目の数値を暗記するのではなく、「動いている頂点 $(a)$ が固定された区間の門をいつくぐるか」を図上で追うことが極意です。

ACTIVITY 4 • 代数と幾何の融合

円上の一次式 — 代数と図形をつなぐ

$x^2 + y^2 = 1$ をただの式と見ず、「原点中心の半径1の円」と読み替えます。$x + 2y = k$ の平行移動で最大・最小が見える！

問題 $x^2 + y^2 = 1$ のもとで、$x + 2y$ の最大値・最小値を求めよ。
円 $x^2+y^2=1$ 直線 $x+2y=k$ 原点からの距離 $d$
共有点あり (実数解存在)
直線の切片パラメータ $k$ を動かす: k = 0.00
-3.5 +3.5
接する限界点へジャンプ:

共有点の判定基準: 距離 $d$ と 半径 $r$ $d \le r$

原点 $(0,0)$ から直線までの距離 $d = \frac{|k|}{\sqrt{1^2 + 2^2}}$: 0.00
0 (中心) 半径 $r = 1.0$ (接する限界) 1.5+ (離れる)

2つの視点が完全に一致する奇跡

① 図形として見る（点と直線の距離）

直線 $x + 2y - k = 0$ が円と交わる条件は、原点からの距離が半径以下：

$\frac{|-k|}{\sqrt{1^2 + 2^2}} \le 1 \iff |k| \le \sqrt{5} \iff -\sqrt{5} \le k \le \sqrt{5}$
② 代数として見る（Cauchy-Schwarz / ベクトル）

$(ax+by)^2 \le (a^2+b^2)(x^2+y^2)$ より：

$(x + 2y)^2 \le (1^2 + 2^2)(x^2 + y^2) = 5 \times 1 = 5$

ベクトル $\vec{u}=(1,2)$ と $\vec{v}=(x,y)$ の内積 $\vec{u}\cdot\vec{v} = |\vec{u}||\vec{v}|\cos\theta$ の最大値とも一致！

FINAL CHALLENGE & 自習問題 • 逆手流・存在条件の本質

分数式の値域を「円と直線の共有点」に変える

一見おそろしい分数式も、「$=k$ と置いて分母を払えば直線になる」。その直線が円と交わる $k$ こそが、値域そのものです！

対象条件と分数式 条件: $x^2 + y^2 = 1$ のもとで、 $k = \frac{x+2y+3}{x+y+2}$ の値域
分母チェック: $x+y \ge -\sqrt{2} \implies x+y+2 > 0$ で0除算なし安全
円 直線 $(k-1)x+(k-2)y+...=0$ 原点からの垂線
$k$ は存在可能（実数解あり）
式の値 $k$ を動かして直線と円の共有点をテスト: k = 1.50
0.0 3.0
中心 $(0,0)$ から直線への距離 $d(k)$ d = 0.63
0.0 半径 $r = 1.0$ (境界) 2.5+
入試最重要の翻訳フロー
1. 分母を払って直線にする

$(k-1)x + (k-2)y + (2k-3) = 0$

2. 円との共有点条件 $d \le r$ に持ち込む

$\frac{|2k-3|}{\sqrt{(k-1)^2 + (k-2)^2}} \le 1$

3. 2乗して $k$ の2次不等式を解く

$2(k-1)(k-2) \le 0 \iff 1 \le k \le 2$

CORE PRINCIPLES • 80分で持ち帰る「受験数学の見方」

数式に命を吹き込む6つの思考OS

問題の数字や記号が変わっても、背後にある「ものの見方」は共通です。初見の入試問題でペンが止まったら、この6つの問いを思い出してください。

01

比が出たら「移動」を見る

公式の丸暗記はクロス掛けミスを生む。「全体の移動量 $(B-A)$ のうち、何分の何進むか」というベクトル感覚を持てば、平面も空間も一貫して解ける。

02

式の値は「欲しい形」を狙う

未知数を解くのが目的ではない。「求めたい式」から逆算し、与式を割る・足す・2乗して塊（ブロック）の関係性を作る。

03

動く2次関数は「頂点の旅」

場合分けの境界は暗記ではない。平方完成した頂点が「固定された定義域の門（端点）」を通過する瞬間から自然に生まれる。

04

条件式を図形として読み替える

$x^2+y^2=1$ は円、$ax+by=k$ は傾き一定の直線群。最大最小は「直線が円と共有点を持って平行移動できる限界」として図で捉える。

05

値域は「$=k$ と置く存在条件」

複雑な分数式も「$=k$」と仮定して分母を払えば直線。その直線が満たすべき図形と交点を持つ条件（$d \le r$ や $D \ge 0$）へ翻訳する。

06

公式は「なぜ使えるか」とセット

点と直線の距離公式も判別式も、本質は「交点を持つか」を言っているだけ。問題に応じて一番計算が短いルートを選択できることが実力。

思考力セルフチェック

次の問いに対して、頭の中で方針が瞬時に浮かぶか確認してみましょう。

Q1. $x^2 - 4x + 1 = 0$ のとき $x^2 + \frac{1}{x^2}$ を求めよと言われたら？
$x=0$ は不適なので両辺を $x$ で割って $x + \frac{1}{x} = 4$ を作る。2乗して $(x+1/x)^2 = 16 \implies x^2 + 2 + \frac{1}{x^2} = 16 \implies 14$。
Q2. $y=(x-a)^2$ の $1 \le x \le 3$ での最小値の場合分け境界は？
頂点 $x=a$ が区間の境界 $x=1$ と $x=3$ をまたぐので、$a < 1$, $1 \le a \le 3$, $3 < a$ の3つ！
Q3. 分数式 $\frac{2x+y+5}{x-y+3}$ の最大最小を円 $x^2+y^2=4$ のもとで解く最初の一手は？
全体を $=k$ と置き、分母を払って $(k-2)x + (-k-1)y + (3k-5) = 0$ という直線の方程式を作る。原点とこの直線の距離が半径2以下（$d \le 2$）になる $k$ の範囲を解く！
