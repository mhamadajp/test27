1 なぜ「角」を分けると「辺の比」が生まれるのか？

基本原理
考えてみよう：角が半分なら、向かいの辺も半分？ 図の頂点Aを左右に大きく動かしてみてください。
「角が半分」だからといって、向かいの辺が真ん中（中点）で分かれるとは限りません！
では、なぜ二等分線は AB : AC という比をつくり出すのでしょうか？
① 角の等しさ → 垂直距離の等しさ DE = DF

直角三角形 △ADE と △ADF は斜辺 AD を共有し、角が等しいため合同です。 したがって、二等分線上の点 D から両辺への距離（垂線）は常に等しくなります。

垂線 DE = 2.12 == 垂線 DF = 2.12
② 同じ2つの三角形の面積比を「2回読む」

△ABD と △ACD の面積比を、2つの異なる「底辺」と「高さ」で表現します：

【見方 A】底辺を AB, AC と見る
高さは共通の垂線 DE = DF。
高さが等しいので面積比は底辺比！
△ABD : △ACD = AB : AC
【見方 B】底辺を BD, DC と見る
高さは頂点Aから直線BCへの共通の垂線 AH。
高さが共通なので面積比は底辺比！
△ABD : △ACD = BD : DC
同じ面積比をイコールで結ぶと…
BD : DC = AB : AC

2 内角の二等分線：内分を「比 ＋ 和」で解く

全体＝和

辺BCの上にある点 D (またはP) は、BCを AB : AC に内分します。 全体である BC は、2つの比の量の「和」に対応します。

線分 BC の分割ビジュアル（テープ図） BC = 4.0
BD: 2.5
DC: 1.5
B側: 5 個分 全体 = 8 個分 C側: 3 個分
比例定数 k を用いた明快な立式

比が 5 : 3 のとき、実際の長さを BD = 5k, DC = 3k と置く。

全体: 5k + 3k = 8k = BC (4.0)
1個分: k = 0.5
BD = 2.5 DC = 1.5
✓ 検算: BD + DC = 4.0 (一致) / BD : DC = 5 : 3

3 外角の二等分線：外分を「比 ＋ 差」で解く

全体＝差
注意ポイント：足し算ではなく「引き算（差）」！ 外角の二等分線と直線BCの交点 Q は三角形の外側にあります。
一直線上の点の並びは B — C — Q です。 したがって、もとの辺 BC は BQ と CQ の「差」 になります！
一直線上の長さの比較（外分構造）
BQ (5k) 10.0
CQ (3k) 6.0
差: BQ - CQ = BC 2k = 4.0
外角の計算手順：
① 比の対応: BQ : CQ = AB : AC = 5 : 3
② CQ = x と置くと、点の順序 B-C-Q より BQ = x + 4
③ 比例式: (x + 4) : x = 5 : 3
5x = 3(x + 4)
2x = 12 → x = CQ = 6, BQ = 10
✓ 検算: 10 : 6 = 5 : 3 / 10 - 6 = 4 (BCの長さと一致)

4 練習問題 ＆ 理解度チェック

確認・定着
【問題1】

△ABC で AB = 4, BC = 8, AC = 7。 ∠A の二等分線と BC の交点を D とするとき、BD を求めよ。

解法プロセス：

1. 角の二等分線より、BD : DC = AB : AC = 4 : 7

2. 全体 BC = 8 は比の和 4 + 7 = 11 個分にあたる。

3. 1個分は 8 / 11 なので、BD（4個分）は：

BD = 8 × (4 / 11) = 32 / 11
※ よくある疑問:「4:7 だから BD=4 になるのでは？」→ 4と7は比の割合であり、実際の長さではありません。全体が8なので、8を11等分した4つ分になります。
【問題2】

△ABC で AB = 5, BC = 4, CA = 3。 内角の二等分線との交点を P、外角の二等分線との交点を Q とするとき、BP, PC, CQ を求めよ。

内角 (P): 比 ＋ 和

BP : PC = 5 : 3

全体 8個分 = 4 → 1個分 = 1/2

BP = 5/2, PC = 3/2
外角 (Q): 比 ＋ 差

BQ : CQ = 5 : 3

差 2個分 = 4 → 1個分 = 2

CQ = 6, BQ = 10
💡 解くコツ: 3-4-5の直角三角形であることは補助的な情報です。比の計算（和と差）の考え方自体はどんな三角形でも変わりません。
