第 1 問 空間図形（回転体の体積・円錐）
基本・必修

図1のように、$\angle C = 90^\circ, BC = 8\text{ cm}, AC = 15\text{ cm}$ である直角三角形 $ABC$ があります[cite: 2]。

  1. 斜辺 $AB$ の長さを求めなさい[cite: 2]。
  2. この三角形 $ABC$ を、辺 $AC$ を回転の軸として $1$ 回転させてできる回転体の体積を求めなさい[cite: 2]。ただし、円周率は $\pi$ とします[cite: 2]。
図1：直角三角形 $ABC$
【解答】

(1) $AB = 17\text{ cm}$[cite: 2]

(2) $320\pi\text{ cm}^3$[cite: 2]

【詳しい解説】

(1) 直角三角形 $ABC$ において三平方の定理より[cite: 2]、 $$AB = \sqrt{BC^2 + AC^2} = \sqrt{8^2 + 15^2} = \sqrt{64 + 225} = \sqrt{289} = 17\text{ cm}$$[cite: 2] (2) 辺 $AC$ を軸として回転させると、点 $C$ を中心として辺 $BC$ が底面の円を作り、頂点 $A$ を頭頂とする円錐ができます[cite: 2]。
・底面の円の半径 $r = BC = 8\text{ cm}$[cite: 2]
・円錐の高さ $h = AC = 15\text{ cm}$[cite: 2]
円錐の体積公式 $V = \frac{1}{3}\pi r^2 h$ に代入すると[cite: 2]、 $$V = \frac{1}{3} \times \pi \times 8^2 \times 15 = 320\pi\text{ cm}^3$$[cite: 2]

第 2 問 空間図形（斜辺軸回転・複合立体）
応用・準2級頻出

第1問の直角三角形 $ABC$（$BC = 8\text{ cm}, AC = 15\text{ cm}, AB = 17\text{ cm}, \angle C = 90^\circ$）について、頂点 $C$ から斜辺 $AB$ に下ろした垂線を $CH$ とします[cite: 2]。

  1. 垂線 $CH$ の長さを求めなさい[cite: 2]。
  2. この三角形 $ABC$ を、斜辺 $AB$ を回転の軸として $1$ 回転させてできる回転体の体積を求めなさい[cite: 2]。
図2：斜辺 $AB$ を軸とする回転
【解答】

(1) $CH = \frac{120}{17}\text{ cm}$[cite: 2]

(2) $\frac{4800}{17}\pi\text{ cm}^3$[cite: 2]

【詳しい解説】

(1) 三角形 $ABC$ の面積に着目すると[cite: 2]、 $$\frac{8 \times 15}{2} = \frac{17 \times CH}{2} \iff CH = \frac{120}{17}\text{ cm}$$[cite: 2] (2) 斜辺 $AB$ を軸として回転させると、$C$ から $AB$ へ下ろした垂線 $CH$ を共通の底面半径とする2つの円錐を合わせた立体になります[cite: 2]。 $$V = \frac{1}{3}\pi \times \left(\frac{120}{17}\right)^2 \times 17 = \frac{4800}{17}\pi\text{ cm}^3$$[cite: 2]

第 3 問 幾何（相似比と体積比）
標準・頻出

図3のように、互いに相似な2つの三角錐 $P$ と $Q$ があります[cite: 2]。三角錐 $P$ の高さは $12\text{ cm}$、三角錐 $Q$ の高さは $18\text{ cm}$ です[cite: 2]。

  1. 三角錐 $P$ と $Q$ の表面積の比を求めなさい。
  2. 三角錐 $P$ の体積が $324\text{ cm}^3$ であるとき、三角錐 $Q$ の体積を求めなさい[cite: 2]。
図3：相似な三角錐 $P$ と $Q$
【解答】

(1) $4 : 9$

(2) $1093.5\text{ cm}^3$[cite: 2]

【詳しい解説】

三角錐の高さの比は $18 : 12 = 3 : 2$ です[cite: 2]。
(1) 表面積比は相似比の2乗なので、$2^2 : 3^2 = 4 : 9$。
(2) 相似な立体の体積比は対応する長さの比の3乗です[cite: 2]。 $$324 \times \left(\frac{3}{2}\right)^3 = 324 \times \frac{27}{8} = 1093.5\text{ cm}^3$$[cite: 2]

第 4 問 数と式・整数（素因数分解と平方数）
基本・必修

$\sqrt{2520n}$ が整数となるような、最も小さい正の整数 $n$ の値を求めなさい[cite: 2]。

【解答】

$n = 70$[cite: 2]

【詳しい解説】

根号内が完全平方数になるよう、素因数の指数をすべて偶数にします[cite: 2]。
$2520 = 2^3 \times 3^2 \times 5 \times 7$[cite: 2]
指数が奇数である因数は $2, 5, 7$ であるため[cite: 2]、 $$n = 2 \times 5 \times 7 = 70$$[cite: 2]

第 5 問 2次関数（判別式と共有点）
標準・最重要

2次関数 $y = x^2 - (k - 4)x + (k - 5)$ （$k$ は定数）について、次の問いに答えなさい。

  1. $k = 1$ のとき、この放物線と $x$ 軸との共有点の座標を求めなさい[cite: 2]。
  2. この放物線が $x$ 軸と異なる2つの共有点をもつための、$k$ の条件を求めなさい[cite: 2]。
図4：放物線と $x$ 軸
【解答】

(1) $(-1, 0), (4, 0)$[cite: 2]

(2) $k \ne 6$[cite: 2]

【詳しい解説】

(1) $k = 1$ を代入し、$x$ 軸との共有点なので $y = 0$ とします[cite: 2]。 $$x^2 - 3x - 4 = 0 \iff (x + 1)(x - 4) = 0$$[cite: 2] $x = -1, 4$ なので共有点は $(-1, 0), (4, 0)$ です[cite: 2]。

(2) 異なる2つの共有点をもつ条件は、判別式 $D > 0$ です[cite: 2]。 $$D = (k - 4)^2 - 4(k - 5) = (k - 6)^2$$[cite: 2] 平方は $0$ 以上で、$k = 6$ のときだけ $0$ になります[cite: 2]。したがって $k \ne 6$ のとき $D > 0$ となります[cite: 2]。

第 6 問 三角比（相互関係）
標準・頻出

$\sin\theta + \cos\theta = \frac{1}{2}$ であるとき、$\sin\theta \cos\theta$ の値を求めなさい[cite: 2]。

【解答】

$\sin\theta \cos\theta = -\frac{3}{8}$[cite: 2]

【詳しい解説】

与えられた和を2乗し、$\sin^2\theta + \cos^2\theta = 1$ を使います[cite: 2]。 $$(\sin\theta + \cos\theta)^2 = 1 + 2\sin\theta\cos\theta$$[cite: 2] $$\frac{1}{4} = 1 + 2\sin\theta\cos\theta$$[cite: 2] $$\sin\theta\cos\theta = -\frac{3}{8}$$[cite: 2]

第 7 問 場合の数（重複組合せ）
応用・準2級頻出

区別のつかない $9$ 個の球を $4$ つの箱に入れる方法は何通りありますか[cite: 2]。ただし、球が $1$ 個も入らない箱があってもよいものとします。

【解答】

$220$ 通り[cite: 2]

【詳しい解説】

$4$ つの箱を $4$ 種類とみなし、$9$ 個の球を重複を許して選ぶと考えます[cite: 2]。 $${}_4\mathrm{H}_9 = {}_{12}\mathrm{C}_9 = {}_{12}\mathrm{C}_3 = \frac{12 \times 11 \times 10}{3 \times 2 \times 1} = 220\text{ 通り}$$[cite: 2]

第 8 問 整数の性質（約数の総和）
標準・頻出

$100$ 以上 $200$ 以下の $12$ の倍数 $n$ のうち、正の約数の和 $\sigma(n)$ が $n$ の整数倍となるような $n$ とその倍率を求めなさい[cite: 2]。

【解答】

$n = 120$ のとき $3$ 倍[cite: 2]

【詳しい解説】

候補は $108, 120, 132, 144, 156, 168, 180$ です[cite: 2]。
各 $n$ を素因数分解して約数の和 $\sigma(n)$ を確認すると、$n = 120$ のとき[cite: 2]： $$120 = 2^3 \times 3 \times 5$$ $$\sigma(120) = (1+2+4+8)(1+3)(1+5) = 15 \times 4 \times 6 = 360$$[cite: 2] $$\frac{\sigma(n)}{n} = \frac{360}{120} = 3$$[cite: 2]

第 9 問 図形と計量（座標平面・中点と距離）
基本・必修

座標平面上に $2$ 点 $A(-2, 5), B(4, -1)$ があります[cite: 2]。

  1. 線分 $AB$ の中点 $M$ の座標を求めなさい[cite: 2]。
  2. 線分 $AB$ の長さを求めなさい[cite: 2]。
図5：2点 $A, B$ と中点 $M$
【解答】

(1) $M(1, 2)$[cite: 2]

(2) $AB = 6\sqrt{2}$[cite: 2]

【詳しい解説】

(1) 中点はそれぞれの座標の平均です[cite: 2]。 $$M\left(\frac{-2 + 4}{2}, \frac{5 + (-1)}{2}\right) = M(1, 2)$$[cite: 2] (2) $x$ 方向の差と $y$ 方向の差から、三平方の定理を使って距離を求めます[cite: 2]。 $$AB = \sqrt{(4 - (-2))^2 + (-1 - 5)^2} = \sqrt{36 + 36} = \sqrt{72} = 6\sqrt{2}$$[cite: 2]

第 10 問 確率・整数の論理
応用・記述

$1$ から $8$ までのカードから同時に $2$ 枚引くとき、積が $3$ の倍数になる確率を求めなさい[cite: 2]。また、整数 $a, b$ について「和 $a + b$ が偶数ならば、$a$ と $b$ はともに偶数、またはともに奇数である」理由を説明しなさい[cite: 2]。

【解答】

確率：$\frac{13}{28}$[cite: 2]

説明例：

整数は偶数か奇数のどちらかである[cite: 2]。偶数を $2m$、奇数を $2m+1$ と表すと、偶数＋偶数と奇数＋奇数はともに $2$ の倍数になるが、偶数＋奇数は奇数になる[cite: 2]。したがって、和 $a+b$ が偶数になるのは、$a$ と $b$ がともに偶数、またはともに奇数の場合だけである[cite: 2]。

【詳しい解説】

全体は ${}_8\mathrm{C}_2 = 28$ 通り[cite: 2]。
積が $3$ の倍数でないのは、2枚とも $3$ の倍数でない場合（$\{1, 2, 4, 5, 7, 8\}$ の6枚から2枚）なので、${}_6\mathrm{C}_2 = 15$ 通り[cite: 2]。
余事象より、 $$\text{確率} = \frac{28 - 15}{28} = \frac{13}{28}$$[cite: 2]
